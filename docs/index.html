Energy Consumption Forecasting

This project demonstrates household energy forecasting using Python, machine learning, and data visualization. The site is published from the /docs folder of the repository.

Project highlights

  • Loads household power consumption data.
  • Performs cleaning, feature extraction, and model training.
  • Uses a Random Forest regressor for prediction.
  • Reports MAE, RMSE, and R² evaluation metrics.

Publishing

To publish this repository as a website, enable GitHub Pages in repository settings and select the /docs folder as the source.

Protecting edits

To prevent direct editing, enable branch protection on the main branch in GitHub settings and require pull request reviews before merging.
